# Quick Start: Windows Desktop Build

## 🚀 Fastest Way to Build Windows Installer

### On Windows:

1. **Clone the repo:**
   ```cmd
   git clone https://github.com/TawfiqulBari/dup-checker.git
   cd dup-checker
   git checkout feature/electron-desktop
   ```

2. **Run the build script:**
   ```cmd
   build-windows.bat
   ```

3. **Done!** Find your installers in the `release` folder:
   - `Dup-Checker Setup 0.1.0.exe` (installer)
   - `Dup-Checker 0.1.0.exe` (portable)

### Prerequisites:
- Node.js (https://nodejs.org/)
- Python (https://python.org/) - check "Add to PATH" during install
